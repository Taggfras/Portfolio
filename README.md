## About this portfolio
In this repository, you can find some of the projects that I have been a part of. The projects are sorted into folders based on the course they were a part of at KTH. Each header below gives a short presentation of the projects in that course.

### [Embedded Systems](/Embedded%20Systems)
In this course, the project was to program an embedded system simulating a traffic intersection to function as specified. The folder contains a [report](/Embedded%20Systems/Intersection%20Light%20Control.pdf) that was written for the project, as well as a folder containing the [code](/Embedded%20Systems/traffic-light) written for the project. The code was compiled, uploaded, and tested on the board using STM32CubeIDE.

### [Algorithms and Data structures](/Algorithms%20and%20Data%20structures)
The course consisted of multiple smaller assignments that led up to a more complicated final assignment. Included in this folder are the seccond to last and the last assignment. The seccond to last assignment is called [TrainsSweden](/Algorithms%20and%20Data%20structures/TrainsSweden) and includes a [report] and the source code. The final assignment is called [TrainsEU](/Algorithms%20and%20Data%20structures/TrainsEU) and also includes a [report] and all the source code for that assignment.
