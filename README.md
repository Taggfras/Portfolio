## About this portfolio
In this repository, you can find some of the projects that I have been a part of. The projects are sorted into folders based on the course they were a part of at KTH. Each header below gives a short presentation of the projects in that course.

### [Embedded Systems](/Embedded%20Systems)
In this course, the project was to program an embedded system simulating a traffic intersection to function as specified. The folder contains a [report](/Embedded%20Systems/Intersection%20Light%20Control.pdf) that was written for the project, as well as a folder containing the [code](/Embedded%20Systems/traffic-light) written for the project. The code was compiled, uploaded, and tested on the board using STM32CubeIDE.

### [Algorithms and Data structures](/Algorithms%20and%20Data%20structures)
The course consisted of multiple smaller assignments that led up to a more complicated final assignment. Included in this folder are the seccond to last and the last assignment. The seccond to last assignment is called [TrainsSweden](/Algorithms%20and%20Data%20structures/TrainsSweden) and includes a [report](/Algorithms%20and%20Data%20structures/TrainsSweden/Pathfinding%20in%20C.pdf) and the source code. The final assignment is called [TrainsEU](/Algorithms%20and%20Data%20structures/TrainsEU) and also includes a [report](/Algorithms%20and%20Data%20structures/TrainsEU/Pathfinding%20using%20Djikstras%20Algorithm.pdf) and all the source code for that assignment.

### [Computer Technology](/Computer%20Technology)
In this course, the project consisted of making a game that could be run on a RISC-V board. The folder contains a [report](/Computer%20Technology/Life%20With%20Adventure.pdf) and a folder containing the [source code](/Computer%20Technology/LifeWithAdventure) for the project.
